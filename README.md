# Εργασιες για το μάθημα προγραμματισμος διαδικτυου

Για την γρηγορη εκκινηση εργασιων και προτζεκτ σε React.js εχω δημιουργησει ενα _'κενο'_ GitHub repo με κάποια προ εγκατεστημένα πακετα οπως το ESLint(linter), το Prettier(formatter).
Περισσότερες πληροφορίες [εδω](https://github.com/tBaronDar/omakase-frontend)

Στην παρούσα εργασια δημιουργώ εναν [router](https://github.com/tBaronDar/ergasies-web-dev/blob/main/src/config/create-router.jsx) οπου καθε route εχει το όνομα του αρχείου που ζητηται στην εκφώνηση των ασκήσεων(π.χ. ex-03-start).


Για να το τρέξετε:

```bash
# To download the nessecary packages
npm install
#Then to run on browser
npm run dev
#Visit http://localhost:5173/ on the browser
```
